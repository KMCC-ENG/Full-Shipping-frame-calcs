# Verification record — 6 November 2026

This record concerns implementation of a nominal elastic planar beam/contact model. It is not a lifting-design qualification. Example geometry is illustrative.

## Analytical comparisons

The reference beam is simply supported over 48 in with total downward load 1,000 lbf, E=29,000,000 psi, I=2 in⁴, effective shear area 2.5 in² and nu=0.30. Both bending and shear deflection are included. The second member in these fixtures is unloaded and independent.

| Reference | Closed-form movement (in) | Computed movement (in) | Relative error |
| --- | ---: | ---: | ---: |
| central_point_load | 0.0401544828 | 0.0401544828 | 1.56e-10 |
| uniform_load | 0.0250427586 | 0.0250427586 | 1.59e-10 |

Both cases returned approximately 500 lbf per lifting point. An off-centre point load at x=12 in returned 750/250 lbf, and its incompatible equal-reaction option was rejected. A resultant outside the lifting-hole interval is rejected if it requires a downward chain force.

Detailed per-beam stress/deflection values, rod-tension changes, contact-solver records, equilibrium residuals and tested Python/package versions are in `verification.json`. Beam-bearing and rod forces satisfy their unilateral contact/finite-stiffness compatibility checks. End-displacement integration agrees with the element-end solution.

The illustrative four-layer example exceeds the default frame yield strength. The UI flags that; linear elastic stresses/deformations are not a plastic-capacity calculation.

## Test coverage and interface checks

The Python suite covers analytic section/beam results, cut material, bearing alignment in section depth, partial-length welded components, finite rod stiffness, opening/closing contact, rectangular-pad engagement, asymmetric/equal lifting reactions, downward chain-reaction rejection, mesh changes, active 2/3/4/5-layer cases, save/load validation, input controls, section-editor mounting and the worked worksheet.

The section sketcher is tested locally in a JavaScript DOM: numerical and mouse geometry, material subtraction, closed outlines, arcs, fillets, snap/ortho, dragging, transforms, pan/zoom, undo/redo and model-change emission. All 98 formulas generated by the four-layer worksheet were parsed successfully with KaTeX. SVG frame/section/FBD images were rendered and inspected locally.

The full app was not visually exercised in a live browser. Automatic approval review rejected the external cloud-browser preview because it could transmit frame data; local Streamlit AppTest and DOM tests were used instead. These tests do not replace inspection of the deployed app on the user's browser.

Final Python suite: **21 passed**. The JavaScript sketcher checks also passed. Check outputs accompany this record. No external deployment or GitHub repository modification was performed.
